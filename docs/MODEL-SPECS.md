## 2. 渠道协议硬上限

| 渠道 | 协议硬上限 | 说明 |
|---|---|---|
| **CodeArts** | 调用预算 `≤ 65,536` | CodeArts `/api/v2/chat/completions` 网关 `RANGE_VALIDATOR` 允许 `0..65536`（`/v1/model/builtin` 实测下发 `65536`/`65535`）；不再沿用旧 v1 的 `32,000` 限制。高于 64K 的目录输出规格与默认调用预算分开展示。 |

## 3. 显示名与实际绑定解耦规则

- `1,000,000` 与 `1,048,576` 均显示为 **`1M`**，点击时按当前模型实际接受的数字绑定（如 Qwen 4 Max 绑定 `1,000,000`，Kimi K3.1 Pro 绑定 `1,048,576`）。
- `500,000` 与 `524,288` 均显示为 **`500K`**（上下文）或 **`512K`**（输出）。
- `256,000` 与 `262,144` 均显示为 **`256K`**；`128,000` 与 `131,072` 均显示为 **`128K`**；`64,000` 与 `65,536` 均显示为 **`64K`**。
- 不展示 `1024K`、`262K`、`131K`、`16K`、`32K`（除协议硬上限 32K 外）等无意义档位。
